လူတွေများကြားထဲမှာ မင်းကိုတွေ့ခဲ့တဲ့နေ့ကစပြီး
နေ့တိုင်းအမှတ်ရနေမိတာ မင်းတစ်ယောက်တည်းပါ။
စကားနည်းနည်းပဲပြောရင်တောင် စိတ်ထဲမှာ တစ်နေ့လုံးပျော်နေတတ်တယ်။
မင်းရဲ့အပြုံးလေးတစ်ခုကပဲ ငါ့ရဲ့ပင်ပန်းမှုတွေကို မေ့သွားစေတယ်။
အချိန်တွေဘယ်လောက်ပြောင်းပြောင်း မင်းအပေါ်ထားတဲ့ခံစားချက်ကတော့ မပြောင်းဘူး။
အနားမှာရှိခွင့်ရရင် အကောင်းဆုံး၊ အဝေးကနေပဲဖြစ်ဖြစ် မင်းပျော်နေတာကို မြင်ရရင်လည်း ကျေနပ်ပါတယ်။
တစ်နေ့နေ့မှာ ငါ့ရဲ့ရိုးသားတဲ့စိတ်ကို မင်းနားလည်ပေးနိုင်မယ်လို့ မျှော်လင့်နေမိတယ်။
မင်းဟာ ငါ့အတွက် သာမန်လူတစ်ယောက်မဟုတ်ဘဲ၊ နေ့တိုင်းအမှတ်ရနေမိတဲ့ အထူးလူတစ်ယောက်ပါ။ ❤️
